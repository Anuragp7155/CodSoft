# ☕ Java Internship Projects Collection

## 📌 Overview

This repository contains a collection of Java projects completed during my internship. These projects were developed to strengthen core Java programming skills, object-oriented programming (OOP) concepts, problem-solving abilities, and application development fundamentals.

The repository includes practical applications that simulate real-world scenarios and demonstrate the use of Java programming concepts such as classes, objects, loops, conditional statements, methods, arrays, and user interaction.

---

## 🚀 Projects Included

### 🏧 ATM Interface
A console-based ATM application that allows users to:
- Check account balance
- Deposit money
- Withdraw money
- View transaction details

### 🎓 Student Management System
A management system for handling student records:
- Add student details
- View student information
- Update records
- Manage student data efficiently

### 📊 Student Grade Calculator
A Java application that:
- Accepts student marks
- Calculates total and average marks
- Assigns grades
- Displays academic performance

### 🎮 Number Game
An interactive guessing game where:
- The system generates a random number
- Users attempt to guess the number
- Feedback is provided for each attempt
- Score and attempts are tracked
